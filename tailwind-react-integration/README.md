# Tailwind React Integration

This project demonstrates how to integrate Tailwind CSS into a React application using Vite.

## Steps Followed

1. Created a new React app using Vite.
2. Installed Tailwind CSS and @tailwindcss/vite plugin.
3. Configured the Vite plugin in vite.config.js.
4. Imported Tailwind in src/index.css.
5. Verified installation by running the development server.

## Run Project

```bash
npm install
npm run dev
